## What's on the site

- **Projects:** a quadrotor hover controller (LQR), [Tradbot-Engine](https://github.com/shekinahudegbue/Tradbot-Engine) (a C++ limit order book), a field service and work-order platform on AWS, and a spatial AI assistant from HackTX 2024
- **Experience:** software engineering internships, AI model evaluation, and my current role as a pharmacy technician
- **A live order book demo** at the top of the page, a small simulation of how buy and sell orders meet

## How it's built

- One self-contained `index.html` file using plain HTML, CSS, and JavaScript, with no frameworks or build step
- Responsive layout that works on phones and desktops
- Automatic light and dark mode based on your system settings
- Respects reduced-motion settings, so the order book demo stays still for anyone who turns animations off
- Hosted for free on GitHub Pages
